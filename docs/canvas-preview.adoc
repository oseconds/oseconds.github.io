= Canvas Preview

A small interactive tool for previewing finished visuals in a Spotify Canvas-style environment.

Canvas Preview is designed around a simple workflow:

[source,text]
----
Video Source
     ↓
Canvas Preview
     +
Track / Audio Settings
     ↓
Check how the visual works with music
----

Instead of editing videos again, the goal is to quickly combine existing visual loops with different tracks and check the result in a mobile Canvas-like preview.

== Concept

The project is not intended to be a video editor.

The videos are assumed to already be finished loops or hard cuts.

The tool focuses on the final combination:

[source,text]
----
Finished Visual
       +
Music
       +
Canvas UI
       ↓
Quick Preview / Verification
----

This makes it possible to reuse existing visual work as a small Canvas library and quickly test different combinations.

== Source Library

Video sources are stored as typed data rather than being hard-coded into the UI.

[source,typescript]
----
export interface VideoSource {
    id: string;
    title: string;
    artist: string;
    video: string;
    defaultBpm: number;
    recommendedBars: number;
    tags: string[];
}
----

Each source contains its own metadata.

The source ID is stored in Canvas State and the full `VideoSource` is resolved from `videos.ts`.

[source,text]
----
Selected Video ID
      ↓
videos.ts
      ↓
VideoSource
      ├── video
      ├── title
      ├── artist
      ├── defaultBpm
      └── recommendedBars
----

This structure is intended to scale into a larger visual library.

== Architecture

The application is structured around a shared Canvas State.

[source,mermaid]
----
graph TD
    USER[User]

    USER --> LIBRARY[Source Library]
    USER --> CONTROLS[Controls]

    LIBRARY --> STATE[Canvas State]
    CONTROLS --> STATE

    STATE --> LOGIC[Utility Logic]
    LOGIC --> STATE

    STATE --> PREVIEW[Preview]
----

The main principles are:

- Source Library selects a Video ID.
- Controls modify the user's current settings.
- Canvas State stores the current preview state.
- Utility modules handle BPM, Loop and Media calculations.
- Preview visualizes the current state.
- Source defaults should not blindly overwrite user-customized values.

== Direction

Canvas Preview aims to become a small working tool for creators:

[source,text]
----
Browse visual assets
        ↓
Choose a Canvas
        ↓
Load / enter track information
        ↓
Match visual + music
        ↓
Check Canvas presentation
----

The project intentionally stays smaller than a video editor.

The focus is on **combining finished visual assets with music and quickly verifying the result in a Canvas-like environment**.
